무엇을 사고, 어떻게 연결하는가

구역 3개(Z1·Z2·Z3)를 만드는 데 필요한 부품과 각 부품의 역할, 연결 방법입니다. 연결도의 부품을 누르거나 카드의 “연결도에서 보기”를 누르면 해당 부품이 강조됩니다.

⚠검토용 제안 · 실물 검수 전입니다. 핀 번호는 클래식 ESP32 DevKit 기준이며 보드를 받은 뒤 확정합니다 (설계서 20.2).

1. 전체 흐름: 데이터와 명령

센서 값은 구역 노드에서 노트북으로 올라가고, 점검 명령은 안전 검사를 거쳐 내려옵니다. 서버가 멈춰도 펌프는 보드에서 스스로 멈춥니다 (설계서 2.1·2.2).

2. 한 구역의 배선 (구역마다 같음)

ESP32 한 대가 센서 5개(온습도 2, 수분 2, 로드셀 1)를 읽고 펌프 1대를 제어합니다. 12V 펌프 전원과 3.3V 센서 전원은 분리하고, 신호 기준 접지만 공유합니다 (설계서 20.1, 29.3, 29.4).

3.3V 신호·센서 12V 펌프 전력 USB 5V (보드 전원) 점선 테두리 = 모델 미정

3. 물길 (구역마다 독립)

물통 하나에서 튜브 3개가 각 구역 펌프로 따로 나갑니다. 어느 구역에 물이 갔는지 구분해야 하므로 펌프 이후의 물길은 합치지 않습니다. 출수구는 프레임에 고정하고 화분이나 계량판을 누르지 않게 합니다 (설계서 20.3, 29.5).

4. 부품별 역할과 연결

그림은 이해를 돕기 위한 단순화한 선화입니다. 실제 모양은 각 카드의 구매 페이지에서 확인하세요.

5. 아직 사지 않았거나 정하지 않은 것

가격이 0원이 아니라 미확정인 항목입니다 (설계서 19.4). 10kΩ 저항은 소액이지만 1차 구매에 꼭 넣어야 합니다.
